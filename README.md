# Northcroft QS Workspace

A team workspace for the Northcroft quantity surveying team in Saudi Arabia. It works in any browser and installs on iPhone and Android like a normal app, with push notifications.

## What it does

- **Projects**: an overview, a task list and board, the variation (VO) register, BOQ package stages, project chat, files and a full history.
- **Tasks**: you assign work with due dates, priorities and checklists, to one person or several. Everyone on a task sees it in My tasks and gets its notifications; any of them can start it, edit its details, steps and files, and submit it for review. Hassan or a senior approves it or sends it back with a note, and only managers and seniors change who's on a task. Tasks can also repeat daily, weekly or monthly.
- **Celebrations**:
  - When Hassan or a senior approves a task (or marks it done), confetti in navy, red and gold bursts across the screen with a glossy card: "Approved. Great work, Imthath and Najeefar."
  - Everyone on that task sees it once too, the next time they open the app (or straight away if it's open): "Hassan approved your work. Great job, Najeefar." Several approvals at once show as one card.
  - Handing work in a day or more before its due date gets a big "Great job, 2 days early". Handing it in on the due day gets a smaller "Right on time". Late work gets the normal message.
  - Work handed in early keeps a gold-on-navy **Finished early** badge in lists and on the task, so it's easy to spot when reviewing.
  - A short chime and, on Android, a small buzz go with it. Switch them off per phone in Settings > Appearance > Celebrations. iPhones stay quiet when on silent and don't buzz. With reduce-motion on, the card shows without confetti.
- **Google Drive links** on tasks and on a project's Files tab (and in the New task form):
  - Paste a Google Drive folder or file link (shared as "Anyone with the link") and its files show right there: step into subfolders, open PDFs, Excel files and photos in the app's own viewers, or download. Google Docs, Sheets and Slides come through as PDF or Excel.
  - Editing a file from a link saves a copy to the task's own files; the file in Google Drive stays as it was.
  - On a repeating task, a link added when it's set up comes with every copy. Whoever added a link, or a manager or senior, can take it off.
  - Needs a one-time Google key, which a manager adds in Settings > Google Drive (step-by-step there, about 5 minutes).
- **Files on a new task**: *Add files* in the New task form attaches drawings, BOQs, PDFs and photos as the task goes out. The form shows each file's progress and opens the task once they're all up. If one fails, the task is still sent and it says which file to add again from the task's Files.
  - On a repeating task, the files come with every copy (marked *Every repeat*). They're stored once, and the copies already made keep them even if the repeating task is removed.
- **Variations and BOQ packages** can have several owners too; all of them get the updates and reminders.
- **Priority** on every task, VO and BOQ package, shown everywhere as a glossy badge:
  - **Urgent**: deep red with a soft glow (the glow stays still if the phone's reduce-motion setting is on).
  - **High**: red.
  - **Normal**: yellow. New items start as Normal.
  - **Low**: green.
  - Pick it with the four buttons in the task, VO or package form. Finished tasks keep their badge, faded.
- **Announcements**: everyone taps *Acknowledge*. Managers see who hasn't, and can nudge them. Anyone who hasn't acknowledged gets an automatic reminder the next morning.
- **Inbox and push notifications**, WhatsApp style:
  - The sender's name is the title. On Android and computers their photo shows beside the message, or their initials if they have no photo. iPhone always shows the app icon for Home Screen apps.
  - One notification per chat or task. It updates with the latest message and a count, and clears when you open that chat or task.
  - Sent for:
    - new tasks, review requests, approvals and requested changes
    - every team chat and project chat message
    - @mentions, and comments on tasks you follow
    - announcements and calendar invites
    - 8:00 am reminders, Sunday to Thursday, for work that's due or overdue
- **Check-in and check-out reminders**, on working days, for everyone set to check in:
  - 8:30 am: "Good morning Imthath. It's 8:30 and you haven't checked in yet. Tap to check in." Not sent to anyone with a Leave entry on the Calendar that day.
  - 5:30 pm: "Remember to check out when you leave", and at 6:30 pm "you're still checked in" for anyone who still hasn't.
  - Each goes out once a day. Checking in or out marks that day's reminder as read. The times follow the working hours in Settings > Working hours.
- **Calendar**: task due dates, VO action dates, BOQ deadlines, site visits and meetings.
- **Check in and check out** with location:
  - Each check-in is labelled Office, a project site or Elsewhere.
  - Late arrivals and early finishes are flagged against 8:30 am to 5:30 pm.
  - Managers get a team board with a map and a monthly CSV export.
- **Workload**: open tasks per person per week, shown in red when someone has too much.
- **Chats**, like WhatsApp:
  - One Chats page: Team chat pinned on top, then project chats, groups and one-to-one chats, newest first, with unread counts (also on the Chats tab).
  - **One-to-one chats**: New chat, or the Message button on anyone's profile card.
  - **Groups**: anyone can start one, name it and pick who's in it. The person who made it is its admin and can make others admins. Admins rename the group and add or remove people; anyone can leave. A group always keeps an admin.
  - Group and one-to-one chats are **private**: only the people in them can read their messages, files and voice notes. Managers can't see chats they're not part of.
  - **Seen ticks**: one tick sent, two ticks seen by some, bright two ticks seen by everyone. Tap the ticks to see who has seen it and when.
  - **Reply** to a message (swipe it right on a phone, or the reply arrow on a computer); the reply quotes it, and tapping the quote jumps to it.
  - **Reactions**: hold a message (or right-click) for Like, Done, Love, Haha, Thanks and Sad.
  - "Saheeb is typing..." shows at the top of the chat.
  - Voice notes, files and @mentions work in every chat. Project chats also stay inside each project.
- **Voice notes** in team chat, project chat, task comments and announcements:
  - Tap the microphone, speak (up to 3 minutes), then send. Others get a play button with a waveform.
  - Each note is written out in English a few seconds later, even if spoken in Arabic or Tamil. The sender can correct the text.
  - In the New task (and Edit task) form, **Record a voice note** under Details: its English text goes straight into Details to check and edit before sending, and the recording goes on the task as a voice note the team can play. For a repeating task, the text is kept in the details and the recording isn't.
- **PDF, Excel and photos inside the app**: tapping a PDF, a spreadsheet (Excel or CSV) or a photo opens it full screen in the app, with tools to edit it.
  - PDF: mark up (pen, highlighter, arrows, boxes, clouds, notes), sign and stamp, rotate, reorder, remove and join pages, measure lengths and areas at the drawing's scale, change existing text (the old words are wiped from the file), add text and pictures, and fill in forms.
  - Excel: every sheet with its formatting, edit cells and formulas (they recalculate), insert and remove rows and columns, basic formatting, find. Charts, macros and pivot tables can't be edited and aren't in the saved copy; the original keeps them.
  - Photos: pinch to zoom, swipe between the photos in the same chat or task, turn, and mark up with arrows, boxes, lines, a pen and text. Saving never changes the original: the edit is saved as a new version next to it (version 2, 3 and so on), with who edited it and when, and you can switch between versions. A file shared in a chat or on a task comment is shared again there as the new version.
- **Files and Google Drive**: attach drawings, BOQs, PDFs and photos to tasks, projects and chats.
  - Every file anyone attaches is saved straight to the team's Google Drive (the one a manager connects), in a **Northcroft** folder with a subfolder per project (plus General). Files of any size; a progress figure shows while they upload.
  - Drive files stay private. Only signed-in team members can open them, through the app (PDFs, photos and videos open in the browser; other files download). Photos show as previews in chats and file lists. Deleting one in the app moves it to the Drive bin for 30 days.
  - A manager connects Google Drive once in **Settings > Google Drive**, which has the step-by-step set-up. The app can only see the files and folders it creates, nothing else in that Drive.
  - Until Drive is connected, files up to 50 MB are kept in the app's own storage. Voice notes, profile photos and project covers always stay in the app's storage.
- **Profiles and WhatsApp**:
  - Everyone adds a photo and a +966 mobile number the first time they sign in.
  - Tap anyone's photo to see their card, with WhatsApp, call and email buttons.
  - WhatsApp buttons also sit on the Team list, the attendance board and task pages. On a task, the WhatsApp message starts with the task name and a link to it.
  - People's check-ins show on the attendance map as their photo.
- **Updates load on their own**: phones keep the app open in the background, so it checks for a new version whenever it comes back to the front (and every 20 minutes). With nothing open it reloads straight away; if a form, a file or typed text is open, an *Update* bar shows instead, so nothing is lost.
- **Liquid glass design**, light by default (Dark or Automatic in Settings > Appearance).
  - Glass is on for everyone. *Solid surfaces* in Settings > Appearance swaps it for solid panels on that phone, if someone finds text hard to read; it's off unless they turn it on, and the phone's own accessibility settings don't switch it on.
  - The light theme is see-through glass over a soft blue and red background, with a bright rim and a glossy shine across the top of each card.
  - Every page opens with a navy glass header with the Northcroft tower behind it; the side menu, top bar and tab bar are navy glass too.
  - Main buttons are glossy Northcroft red; other buttons are frosted glass.
  - Navy is the main colour; Northcroft red marks counts, urgent items, the active tab and New task.
  - Home opens with a banner of the Northcroft tower, a greeting and a one-line summary of your day.
  - Projects can have a cover photo (Hassan and seniors add it on the project page).
  - Empty screens show small navy and red drawings, and sections have coloured icon tiles.
  - Gentle motion: sections rise in, numbers count up, a tick draws when a task is finished. It switches off if the phone's reduce-motion setting is on.

## Who can do what

| | Managers: Fawaz (Commercial Manager) and Hassan | Seniors (switched on in Settings > Team) | Team members |
|---|---|---|---|
| Create and assign tasks, approve work | Yes (with the two-step sign-off below) | Yes | No |
| Post announcements, create projects | Yes | Yes | No |
| See everyone's attendance | Yes (Fawaz: present, absent or on leave only) | Yes | Own only |
| Add people, reset passwords, set hours, office pins | Yes | No | No |
| Change who's on a task, delete tasks | Yes | Yes | No |
| Edit a task's details, steps and files, and submit it | Yes | Yes | When they're on the task |
| Update VOs and BOQ packages, comment, chat, upload files | Yes | Yes | Yes |

Work flows down: Fawaz gives tasks to Hassan, and Hassan gives tasks to the team. Two switches in Settings > Team control this for anyone:

- **Checks in and out**: off for Fawaz. He has no Check in tab and isn't on the attendance board, map, late list or monthly export. Managers who don't check in still see everyone else's attendance.
- **Can be given tasks**: off for Fawaz. He doesn't appear in anyone's "Assign to" list (the database blocks it too), but he can give himself a reminder task. Instead of My tasks he has **Assigned tasks**: every open task in the team, person by person, his Final OK list, and the team's recently finished work.
- **Sees check-in times** (managers and seniors): off for Fawaz. He sees who is present, absent or on leave each day and the monthly totals, but no check-in or check-out times, places or map. The database enforces this: the `team_presence` function gives him the day-by-day status only.

### Task sign-off in two steps

Settings > Team > Task sign-off sets who checks handed-in work first (Hassan) and who gives the final OK (Fawaz).

- A task handed in goes to Hassan first. When he approves it (or marks it done), it goes to Fawaz, and only Fawaz's final OK makes it Done. The celebration for the team comes with the final OK.
- Either of them can send it back with notes. A task Fawaz sends back goes to the people on it and Hassan hears about it too. When it's handed in again, Hassan checks it first again.
- Hassan's own tasks go straight to Fawaz. A task Fawaz is on finishes at Hassan's OK.
- Fawaz can't approve before Hassan has checked, and Hassan can't give the final OK. The database enforces the order (`guard_task`), whatever screen is used.
- Clear the Final OK in Settings to go back to one reviewer per task.

Hassan and Fawaz both have an **Ongoing tasks** card on Home with every open task, grouped by person, late ones first.

Drive links can also be added to any message (team chat, project chats, groups, one-to-one chats and task comments) with the link button next to the paperclip. A link in a message is seen by the people who can see that message, so links in a private chat stay private.

## Tech

- **Front end**: React, TypeScript and Vite, built as a PWA. The service worker is in `public/sw.js`.
- **Back end**: Supabase project `hfekwhvnyzpneydqrnsz` in the `ap-south-1` (Mumbai) region.
  - Postgres with row level security on every table.
  - Database triggers create notifications and keep the activity history.
  - `pg_cron` runs reminders at 08:00 Riyadh time and recurring tasks at 05:00.
  - Storage bucket `files` holds attachments.
  - Edge Functions:
    - `send-push` sends Web Push messages, signed with VAPID keys kept in Supabase Vault.
    - `admin-users` lets the manager add people and reset passwords.
    - `transcribe` writes voice notes out in English in two steps:
      1. Groq Whisper (`whisper-large-v3`) writes down what was said, in the language it was spoken, and reports the language. This needs a `GROQ_API_KEY` secret. Without it, voice notes still work but show "Voice-to-text isn't switched on yet".
      2. Claude (`claude-opus-5-5`, low effort) finishes it. English is tidied (misheard names, projects and QS terms, punctuation). Arabic, Tamil or any other language is translated into English, keeping names, dates and times exactly; this is much more accurate than Whisper's own translation. This step turns on with an `ANTHROPIC_API_KEY` secret. Without Claude, English is kept as Whisper wrote it and other languages use Whisper's translation.
    - `drive` handles Google Drive for every attachment: connecting (Google sign-in with the `drive.file` permission only), starting uploads that the browser sends straight to Google in 8 MB pieces, attaching them, and streaming them back to signed-in team members through 1-hour signed links. The Google client, refresh token and link-signing key are kept in Supabase Vault.
    - `assist` is retired (it answers "no longer available").
  - Where the Claude and Groq keys live: Supabase Vault, as `anthropic_api_key` and `groq_api_key` (encrypted at rest; read only by the Edge Functions through `get_ai_keys()`). An Edge Function secret with the same name in capitals (`ANTHROPIC_API_KEY`, `GROQ_API_KEY`) takes priority if you add one. The keys are never stored in this repository.
  - To replace a key, run this in the Supabase SQL editor (a changed key is picked up within 5 minutes):
    `select vault.update_secret((select id from vault.secrets where name = 'anthropic_api_key'), '<new key>');`
- **Database**: the SQL is in `supabase/migrations/`, and the Edge Function source is in `supabase/functions/`.

## Running locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-checks, then builds to dist/
```

The Supabase address, publishable key and VAPID public key are in `src/lib/config.ts`. All three are safe to ship to a browser. To override them, set `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` and `VITE_VAPID_PUBLIC_KEY`.

## Hosting on Vercel

1. Open https://vercel.com/new and import `hashu387-ship-it/Northcroft`.
2. Keep the defaults and press **Deploy**. `vercel.json` already sets the build command, the output folder, and the settings the app and service worker need.

After that, every push to GitHub redeploys the site automatically. Notification links follow whichever web address each phone installed the app from, so nothing needs changing after the first deploy.

## Installing on a phone

- **iPhone (iOS 16.4 or newer)**:
  1. Open the site in Safari.
  2. Tap **Share**, then **Add to Home Screen**.
  3. Open Northcroft from the Home Screen.
  4. Go to **Settings > Notifications** and tap **Turn on notifications**.
- **Android**: open the site in Chrome, tap **Install** when it's offered, then turn on notifications the same way.
